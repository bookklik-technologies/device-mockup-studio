# Device Mockup Studio: spatial (private workspace)

Private implementation module of Device Mockup Studio. Do not publish or install this workspace separately.

Its public API is available from `@bookklik/device-mockup-studio/spatial` inside the single `@bookklik/device-mockup-studio` npm package.

Try the [demo](https://bookklik-technologies.github.io/device-mockup-studio/). ESM only, TypeScript declarations included. Browser rendering is separate from the DOM-free core.
